Como restaurar
  1. Pare o OmniDude.
  2. Guarde o omnidude.db atual (e apague omnidude.db-wal e omnidude.db-shm, se existirem).
  3. Copie o backup para o diretório de dados com o nome omnidude.db.
  4. Mantenha a mesma chave (secret.key) e inicie o OmniDude.
